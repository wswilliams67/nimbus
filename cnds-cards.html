    v1 Cards
    This application is not optimized for small screens. Please use a large tablet, laptop, or desktop computer to continue.

    Cards are slightly elevated sections of information used to display grouped content. They support titles, subtitles, body text, images, icons, avatars, action buttons, links, headers, and footers. Cards come in four types: default, basic, alert, and outline, each with multiple color variants and alignment options.

    Use the default card when you need a container with background, border, and box shadow. Choose .card-basic for a flatter appearance without a shadow, .card-alert for a solid-color card that draws attention to status information, and .card-outline when you want a colored border without filling the background. All types support horizontal layout, header/footer sections, and text alignment utilities.

    Note: Read the API Documentation to find all available options and advanced customization.

    Note: To preview components in different themes, click the theme toggle button / in the header navigation bar.

    CSS Classes

    The following CSS classes are available for building cards.

    Structure Classes
    Class Description
    .card Base card container. Required on the outermost element.
    .card-body Main content area of the card. Contains title, text, and actions.
    .card-top Wrapper for the icon and titles area at the top of the card body.
    .card-titles Container for the card title and subtitle.
    .card-title Card title element (typically <h5>).
    .card-subtitle Card subtitle element (typically <h6>).
    .card-text Card body text paragraph.
    .card-icon Container for an icon displayed before the titles.
    .card-img-top Image placed at the top of the card, above the body.
    .card-actions Container for action buttons at the bottom of the card body.
    .card-links Container for action links (alternative to buttons).
    .card-link Individual link within .card-links.
    .card-header Optional header section above the card body.
    .card-footer Optional footer section below the card body.
    Type Classes
    Class Description
    .card (default) Default card with background, border, and box shadow.
    .card-basic Same as default but without the box shadow.
    .card-alert Solid background color card with no border. Requires a color class.
    .card-outline Colored border with transparent background. Requires a color class.
    .card-horizontal Horizontal layout with image on the left and content on the right.
    Color Classes

    Used with .card-alert and .card-outline to set the card color variant.

    Class Type Description
    .card-brand-blue Brand Cloudficient brand blue color.
    .card-brand-green Brand Cloudficient brand green color.
    .card-primary Semantic Primary / neutral color.
    .card-secondary Semantic Secondary / muted color.
    .card-success Semantic Success / positive color.
    .card-error Semantic Error / danger color.
    .card-warning Semantic Warning / caution color.
    .card-info Semantic Informational color.
    .card-light Semantic Light / subtle color.
    .card-dark Semantic Dark / strong color.
    Layout Classes
    Class Description
    .card-group Groups cards into a single row with equal heights and no gutters.
    .text-center Center-aligns card content.
    .text-end Right-aligns card content.

    CSS Custom Properties

    The following CSS custom properties are defined on the .card element and can be overridden to customize card appearance.

    Property Default Description
    --cnds-card-spacer-y 1.5rem Vertical padding inside the card body.
    --cnds-card-spacer-x 1.5rem Horizontal padding inside the card body.
    --cnds-card-title-spacer-y 0.25rem Vertical spacing between title and subtitle.
    --cnds-card-title-color (inherited) Color of the card title.
    --cnds-card-subtitle-color (inherited) Color of the card subtitle.
    --cnds-card-border-width 1px Border width of the card.
    --cnds-card-border-color #e0e0e0 Border color of the card.
    --cnds-card-border-radius 8px Border radius of the card.
    --cnds-card-box-shadow none Box shadow. Default cards use var(--cnds-box-shadow).
    --cnds-card-color (inherited) Text color of the card.
    --cnds-card-bg #f5f5f5 Background color of the card.
    --cnds-card-cap-padding-y 0.25rem Vertical padding for header/footer caps.
    --cnds-card-cap-padding-x 1.5rem Horizontal padding for header/footer caps.
    --cnds-card-cap-bg transparent Background color for header/footer caps.
    --cnds-card-cap-color (inherited) Text color for header/footer caps.
    --cnds-card-img-overlay-padding 1.5rem Padding for image overlay content.
    --cnds-card-group-margin 0.75rem Margin between cards in a card group.
